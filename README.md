# customer-satisfaction-analysis
# Customer Satisfaction Analysis using Machine Learning

## 📌 Project Overview
This project analyzes customer satisfaction in online shopping platforms using Data Science and Machine Learning techniques.

Customer feedback was collected using Google Forms and analyzed to identify:
- Customer sentiment
- Common complaints
- Satisfaction trends
- Customer behavior patterns

The project applies:
- Classification
- Clustering
- Regression
- NLP/Text Analysis

to generate meaningful business insights.

---

# 🎯 Problem Statement
Online shopping platforms receive thousands of customer reviews and ratings daily. Manually analyzing customer opinions is difficult and time-consuming.

This project aims to automate customer feedback analysis and help businesses understand:
- Customer satisfaction
- Delivery issues
- Product quality concerns
- Pricing satisfaction
- Repurchase behavior

# 📊 Machine Learning Techniques Used

## 1. Classification
Used Logistic Regression to classify customer reviews into:
- Positive
- Negative

### Technique Used
- TF-IDF Vectorization
- Logistic Regression

---

## 2. Clustering
Used K-Means Clustering to group customers based on review similarity.

### Example Clusters
- Delivery-related complaints
- Product quality issues
- Pricing satisfaction

---

## 3. Regression
Used Linear Regression to predict customer satisfaction scores.

### Input Features
- Delivery Rating
- Product Quality Rating
- Price Satisfaction

### Target
- Overall Satisfaction Score

---
